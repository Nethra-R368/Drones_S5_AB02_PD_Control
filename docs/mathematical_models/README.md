# Mathematical models

`Mathematical_Models.pdf` — every equation of the paper (blocks 1–6) and of our X3 implementation (blocks 7–10): boxed
statement, symbol table (dimension, unit), derivation, hand-checkable toy example, where it lives in the code, and the
MATLAB step that prints the same numbers. Build: `pdflatex flow_paper.tex` and `pdflatex flow_x3.tex` in `figures/`, then
`pdflatex Mathematical_Models.tex` twice.
